# **幫你算兌 Money Snap \- 產品需求文件 (PRD)**

| 產品名稱 | 幫你算兌 Money Snap \- 兌幣計算機 |
| :---- | :---- |
| **文件版本** | v0.2.0 |

| **核心宗旨** | 讓現金發放與換鈔統計變為秒速、零出錯且 100% 資安安全 |

## **1\. 產品願景與定位**

「幫你算兌 Money Snap」是一款專為財務人員、工作室負責人打造的輔助工具。解決從試算表貼上資料到完成銀行換鈔、包薪資袋之間的繁瑣計算流程。產品堅持 **「免安裝、免註冊、純本地運算」**，確保極致的資料安全。

## **2\. 使用者情境 (User Stories)**

* **US-01（有姓名發薪）**：身為財務人員，我希望貼上 姓名, 金額 清單後，系統能直接算好每個人要發幾張千鈔與百鈔，並給我一份銀行領款總數。  
* **US-02（純金額急件）**：身為工作室負責人，我拿到了一串金額數字但沒有姓名，我希望取消勾選姓名欄位後直接貼上計算，不需要手動捏造名字。  
* **US-03（資料安全）**：身為注重資安的財務，我希望工具不會把員工薪資數據上傳雲端，避免洩漏隱私。  
* **US-04（薪資袋核對）**：身為財務人員，我希望可以將計算出來的明細匯出成圖片，印出來貼在薪資袋上。

## **3\. 功能規格詳述 (Detailed Feature Specifications)**

### **3.1 模組一：資料輸入區 (Data Input Module)**

#### **3.1.1 「貼上資料包含姓名欄位」 Checkbox 開關**

* **UI 呈現**：位於 Textarea 上方，標籤文字為 ☑ 貼上資料包含姓名欄位。  
* **狀態記憶**：勾選狀態變化時，同步寫入 localStorage.setItem('hasNameFlag', boolean)。  
* **互動效果**：  
  * **勾選 (true)**：Textarea Placeholder 顯示 張三, 45,800\\n李四, 32,000。  
  * **取消勾選 (false)**：Textarea Placeholder 顯示 45,800\\n32,000。

#### **3.1.2 內容解析邏輯 (Smart Parser)**

* **模式 A（勾選姓名）**：  
  1. 逐行讀取，以逗號 ,、空格 或 Tab 分隔姓名與金額。  
  2. 左側為姓名，右側過濾出純數字為金額。  
  3. 若姓名重複，自動合併金額。  
* **模式 B（取消勾選姓名）**：  
  1. 逐行讀取，整行過濾所有非數字字元作為金額。  
  2. 姓名自動帶入 項目 \#${index \+ 1}。

### **3.2 模組二：計算與雙重對帳 (Calculation & Verification)**

* **面額拆解順序**：$1000 \\rightarrow \\$500 \\rightarrow \\$100 \\rightarrow \\$50 \\rightarrow \\$10 \\rightarrow \\$5 \\rightarrow \\$1$。

### **3.3 模組三：輸出與導出區 (Output Module)**

#### **3.3.1 銀行領款總需求**

* 顯示所有面額之總需求張數/個數。  
* **一鍵複製領款單**：輸出剪貼簿格式文字：  
  銀行領款單：1000元 77張、500元 1張... 總計 $77,800 元

#### **3.3.2 個人薪資發放明細**

* 以卡片（Cards）呈現個人面額拆解結果。  
* 提供「匯出明細圖片 (PNG)」按鈕（整合 html2canvas）。
